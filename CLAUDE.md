# Shop Project — Agent Instructions

## Архітектура

Це навчальний Python-проєкт системи керування інтернет-магазином.

Проєкт працює з даними в пам'яті та не використовує базу даних.

Основний код знаходиться в каталозі `src/`.

Основні частини проєкту:
- `models/` — моделі даних;
- `products/` — робота з товарами;
- `users/` — робота з користувачами;
- `orders/` — робота із замовленнями;
- `payments/` — робота з платежами;
- `statistics/` — статистика;
- `utils/` — допоміжні функції;
- `tests/` — автоматизовані тести.

Точка запуску програми: `main.py`.
